# Fundamentos de Machine Learning

Este repositorio contiene una colección de cuadernos de Google Colab y recursos para aprender los fundamentos de Machine Learning.

## Uso de Google Colab

Todos los cuadernos en este repositorio están diseñados para ser utilizados con Google Colab. Para ejecutar un cuaderno:

1.  Haz clic en el enlace del cuaderno en el repositorio.
2.  Google Colab abrirá el cuaderno en tu navegador.
3.  Haz clic en "Conectar" en la esquina superior derecha para asignar una instancia de máquina virtual.
4.  Ejecuta las celdas de código una por una o utiliza "Entorno de ejecución" -> "Ejecutar todo".
